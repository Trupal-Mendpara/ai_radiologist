# AI Radiologist

A deep-learning system for automated classification of chest X-ray images,
designed to demonstrate how computer vision can assist in early medical screening.

## Overview
AI Radiologist applies convolutional neural networks to chest X-ray images to
classify radiological findings with high accuracy. The project covers the
end-to-end pipeline of a medical imaging AI system: data preprocessing, model
training, evaluation, and inference.

## Features
- Automated classification of chest X-ray images
- Deep learning model trained on medical imaging data
- Image preprocessing and augmentation pipeline
- Model evaluation with standard classification metrics
